Connect Supabase

Optional until you create your cloud project.

This HTML file cannot create a cloud database by itself. Create a Supabase project, run the SQL schema below, then enter your project URL and public anon/publishable key here. Never put a service-role key in browser code.

The public key is safe to use only with correctly configured RLS policies. Treat customer data as private. Use a Supabase Auth login and user-scoped policies before using this for real customer records.

Database schema

Starter schema for orders and customer records.

Open Supabase → SQL Editor → New query, paste this SQL and run it. This starter schema enables RLS and denies public access by default. Add authentication and owner-scoped policies before syncing real data.

Data & privacy

Understand where your records live.

  • Local mode: records stay in this browser profile on this device.
  • Backup: export a JSON file periodically and store it securely.
  • Cloud mode: configure Supabase Auth and user-scoped RLS policies before enabling production sync. The starter HTML intentionally does not auto-upload private customer data.
  • WhatsApp: the app opens the customer chat with a prepared message and downloads a PDF. You attach the PDF and tap Send manually.
